# Tagtel Connect

A self-service application for Tagtel internet customers in Zimbabwe.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
